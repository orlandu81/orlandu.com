About the Arcade

Everything on this site is readable by an AI assistant, and now callable by one. An MCP server lets Claude, ChatGPT, Cursor, Claude Code or any agent that speaks the protocol search the site, read a page in full and query the open datasets — no key, no account, no scraping.

Three ways in

  • llms.txt — a one-page index of the site for agents: https://www.orlandu.com/llms.txt
  • llms-full.txt — the whole site's text in one Markdown file, about 74,000 words, for an agent that wants to read everything at once: https://www.orlandu.com/llms-full.txt
  • The MCP server — tools an agent can call: https://www.orlandu.com/api/mcp

The MCP server

Endpoint https://www.orlandu.com/api/mcp — Streamable HTTP transport, read-only, no authentication. Six tools:

  • search_orlandu — full-text search over every page, card, glossary term and gallery caption
  • read_orlandu_page — one page as Markdown
  • list_orlandu_pages — every page with its description
  • sony_monitor_specs — the fleet spec table, filterable by model
  • playchoice_10_library — the fifty-two PlayChoice-10 games, each with its board photo
  • console_video_out — how each console reaches the glass

It answers from the published pages only, and it is rebuilt with every update to the site.

Connect it

Wherever your assistant takes a remote MCP server, give it the URL above. In Claude Code it is one line:

claude mcp add --transport http orlandu https://www.orlandu.com/api/mcp

In Cursor, add it to mcp.json:

{ "mcpServers": { "orlandu": { "url": "https://www.orlandu.com/api/mcp" } } }

In Claude it goes in as a custom connector with that URL; ChatGPT and most other assistants that accept a remote MCP server take the same URL. Then ask: "Which Sony monitors at Orlandu's Arcade take BKM cards, and which cards are fitted?" · "What does the PVM-20L5 buying guide say about shipping?" · "Read the PVM vs. BVM piece and tell me which one I want for a Super Nintendo."

The rules

Read-only, free, and rate-limited only by courtesy: one assistant reading a few pages is the use this was built for; a crawler should take llms-full.txt instead. The text and photography are © Orlandu's Arcade, and quoting with attribution is welcome. The arcade is a private collection in a home, not a venue — and the server will tell your assistant the same.
